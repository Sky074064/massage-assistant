BookRelax Chrome Extension for Treatment Notes

NoteFlow helps massage therapists auto-fill professional BookRelax treatment notes directly inside BookRelax. It is built for repeated massage documentation workflows where templates, body chart areas, complaint text, and consistent note fields matter.

What NoteFlow Helps With

BookRelax treatment notes

Fill Examination, Symptom, Treatment Area, Treatment Method, Outcome, and Comment fields with saved clinical wording.

BookRelax auto fill notes

Reduce repetitive typing by using 30, 45, and 60 minute templates with A-E slot rotation.

Massage SOAP note workflow

Keep treatment documentation consistent while still requiring the therapist to verify that every note reflects the actual treatment provided.

How It Works

  1. Install NoteFlow from the Chrome Web Store.
  2. Open your supported BookRelax Work page.
  3. Review and accept the in-extension privacy disclosure.
  4. Create or edit your note templates in slots A-E.
  5. Start auto-fill when you are ready to process treatment notes.

Important Privacy and Product Notes

NoteFlow may read supported BookRelax page content such as appointment details, treatment duration, body chart markers, complaint text, symptoms, and treatment-note fields when needed for note generation. This data is used for the extension's treatment-note workflow. License verification and referral registration are sent securely to Google Apps Script.

NoteFlow is an independent extension and is not affiliated with, endorsed by, or sponsored by BookRelax.
