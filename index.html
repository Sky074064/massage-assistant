購買後怎麼安裝？

1

下載 Extension

點擊下方下載按鈕，取得 massage-assistant.zip，解壓縮到任意資料夾（建議桌面）

2

Chrome 載入

開啟 Chrome → 網址列輸入 chrome://extensions → 右上角開啟「開發人員模式」→ 點「載入未封裝項目」→ 選解壓縮的資料夾

3

付款取得授權碼

在上方輸入 Email 並完成付款，30 秒內自動寄出 License Key 到你的信箱

4

輸入授權碼

點 Chrome 右上角的 🖐 圖示 → 設定 → 貼上授權碼 → 點驗證 → 按鈕解鎖變綠色

5

開始使用

前往 mybookrelax.com Work 清單頁 → 點「開始自動填入」→ 坐著喝咖啡等它跑完
