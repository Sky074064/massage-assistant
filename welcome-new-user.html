BookRelax setup guide

Welcome to NoteFlow

Use this guide after installing NoteFlow from the Chrome Web Store. It helps you set up the BookRelax Chrome extension for treatment notes in a few minutes.

Step 1: Pin NoteFlow in Chrome

Click the puzzle-piece icon in Chrome, find NoteFlow, and pin it to your toolbar. This makes it easier to open the extension while using BookRelax.

Step 2: Open BookRelax

Go to your supported BookRelax practitioner Work page. NoteFlow is designed for BookRelax treatment-note workflows and does not run on unrelated websites.

Step 3: Review Privacy and Consent

On first use, NoteFlow shows a privacy disclosure. Review it before using body chart detection, complaint detection, license verification, or treatment-note auto-fill.

Step 4: Create Treatment Note Templates

Open the Templates tab and set up slots A-E. You can prepare 30, 45, and 60 minute wording for Examination, Symptom, Treatment Area, Treatment Method, Outcome, and Comment.

Step 5: Start Auto-Fill

Return to the BookRelax Work page and click Start. NoteFlow uses supported page content, body chart markers, complaint suggestions, and templates to help fill treatment-note fields.
